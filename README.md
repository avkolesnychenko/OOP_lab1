# 🍕 Pizza Asteroid App

**PizzaAsteroidApp** — це консольний застосунок мовою C#, що моделює та управляє унікальною астрономічною базою даних: космічними астероїдами, які мають властивості піци! Проєкт демонструє базові та просунуті концепції об'єктно-орієнтованого програмування (ООП), роботу з колекціями, переліками (`enum`), валідацію вхідних даних через регулярні вирази, інтерактивне консольне меню та симуляцію фізико-кулінарної поведінки космічних тіл.

## ✨ Основні можливості

- **Керування місткістю сховища:** на початку роботи користувач задає максимальний ліміт ($N$) кількості астероїдів.
- **Два режими додавання об'єктів:**
  - *Ручний режим:* покрокове введення з повною валідацією параметрів.
  - *Автоматичний режим:* випадкова генерація правдоподібних астероїдів ("Пепероні-X", "Квадро-Формаджо" тощо) із рандомізованими фізичними та часовими показниками.
- **Табличний вивід:** акуратне форматування реєстру об'єктів з відображенням індексу, типу тіста, розміру, температури, сирного покриття та дати реєстрації.
- **Фільтрація та пошук:**
  - За типом бортика (`CrustType`).
  - За наявністю додаткового сиру (`HasExtraCheese`).
- **Симуляція унікальної поведінки (`PizzaAsteroid`):**
  - 🔥 `HeatUp(int)`: нагрівання астероїда із перевіркою плавлення сирної скоринки (якщо $T > 60^\circ	ext{C}$).
  - 🍕 `Slice(int)`: розділення астероїда на частини зі зміною його діаметра ($D_{\text{новий}} = \frac{D}{\sqrt{n}}$).
  - 💥 `CollideWithTarget(string)`: симуляція зіткнення з планетою або супутником з утворенням соусного сліду та уламків.
- **Гнучке видалення:**
  - За порядковим номером у реєстрі.
  - За назвою (із підтримкою `OrdinalIgnoreCase`).

## 🏛 Архітектура проєкту

Застосунок розбитий на логічні компоненти відповідно до принципів модульності:

```
PizzaAsteroidApp/
│
├── CrustType.cs        # Перелік (enum) типів тіста / бортиків піци
├── PizzaAsteroid.cs    # Модель космічного астероїда (поля, конструктори, методи поведінки)
└── Program.cs          # Головний клас: меню, цикл роботи, валідатори вводу, CRUD-операції
```

## 🪐 Структура даних

### Сутність `PizzaAsteroid`
| Поле / Властивість | Тип даних | Опис |
| :--- | :--- | :--- |
| `Name` | `string` | Назва астероїда |
| `Crust` | `CrustType` | Тип бортика (Thin, CheeseStuffed, DeepDish, Classic) |
| `DiameterKm` | `double` | Діаметр об'єкта в кілометрах |
| `TemperatureCelsius` | `int` | Поточна температура поверхні в °C |
| `HasExtraCheese` | `bool` | Прапорець наявності подвійного шару сиру |
| `discoveryDate` *(private)* | `DateTime` | Дата відкриття астероїда (інкапсульована через гетер/сетер) |

### Перелік `CrustType`
- `Thin (1)` — Тонке хрустке тісто
- `CheeseStuffed (2)` — Бортик із сирним наповненням
- `DeepDish (3)` — Чиказький стиль / товсте пишне тісто
- `Classic (4)` — Класичне традиційне тісто

## 🛡 Валідація та обмеження

Усі дані, що вводяться користувачем вручну, проходять суворий контроль:
- **Назва:** від 3 до 20 символів; дозволені українські та латинські літери, цифри, пробіли й дефіс (перевірка через регулярний вираз `Regex`).
- **Діаметр:** дійсне число в діапазоні від `0.1` до `1000.0` км (незалежно від використання коми чи крапки як роздільника).
- **Температура:** ціле число від `-273°C` (абсолютний нуль) до `500°C`.
- **Дата відкриття:** формат `dd.MM.yyyy`, у межах від `01.01.1990` до поточної дати.
- **Місткість сховища:** строго $N > 0$.
